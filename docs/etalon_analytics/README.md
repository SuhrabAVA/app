# Аналитика производства

Готовый статический проект на HTML + CSS + JavaScript.

## Что внутри

- `index.html` — структура приложения.
- `styles.css` — весь дизайн.
- `app.js` — демо-логика, таблицы, детализация, графики, localStorage.
- Данные сохраняются в браузере через `localStorage`.

## Как открыть

Просто открой `index.html` в браузере.

## Что уже реализовано

1. Главная страница с кнопками:
   - Сотрудники
   - Рабочие места
   - Графики работы

2. Таблица сотрудников:
   - должность
   - статус
   - имя
   - дни/ночи работы
   - полезное время
   - рабочие места
   - сделанное количество
   - приладка
   - общее количество
   - паузы и проблемы
   - претензии
   - средняя ЗП за день
   - КПД
   - общий итог ЗП

3. Детальная страница сотрудника:
   - переключение сотрудника без выхода на главный экран
   - статистика по рабочим местам
   - календарь смен
   - дневная/ночная/выходной цветами
   - линия времени 08:00–08:00
   - серый — простой
   - синий — работа
   - жёлтый — пауза
   - красный — проблема
   - информационная доска выбранного дня
   - зарплата, авансы, удержания, компенсация

4. Аналитика рабочих мест:
   - таблица рабочих мест
   - единица измерения
   - коэффициент
   - часы работы
   - паузы/проблемы
   - сделанное количество
   - КПД

5. Детальная страница рабочего места:
   - переключение рабочего места без выхода
   - календарь активности
   - линия времени
   - список событий
   - итоговое количество за период

6. Графики работы:
   - таблица сотрудников по дням месяца
   - ячейки переключаются кликом: День → Ночь → Выходной
   - изменения сохраняются

## Как потом подключить реальную базу

Сейчас данные лежат в `app.js` и сохраняются в `localStorage`.

Для подключения Supabase/Firebase/API нужно заменить функции:
- `loadDB()`
- `saveDB()`
- `eventsInFilter()`
- `employeeEvents()`
- `machineEvents()`

А структуру данных можно оставить похожей:
- `employees`
- `machines`
- `events`
- `schedules`
- `salaries`
